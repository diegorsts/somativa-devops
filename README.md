\# Somativa DevOps



API simples em Flask para a disciplina de DevOps.



\## Endpoints



\- GET / - Mensagem de boas-vindas

\- GET /health - Health check

\- GET /info - Informacoes do projeto



\## Como rodar



pip install -r requirements.txt

python app.py



\## Como testar



pytest test\_app.py -v
